# Hildor Júnior - Portfolio Website

Personal site for [hildor.dev](https://hildor.dev), built with Next.js.

## Features

- Responsive layout with Bulma and custom SCSS
- GitHub repositories loaded from the public API
- Latest posts from [blog.hildor.dev](https://blog.hildor.dev)
- Optimized images with Sharp

## Tech Stack

- **Framework:** Next.js 16
- **Language:** TypeScript
- **Styling:** SCSS + Bulma
- **Dates:** Day.js
- **Images:** Sharp
- **Hosting:** Vercel

## Getting Started

Requires Node.js 20.9 or higher.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm start
```
